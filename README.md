# 📈 Paid Search Internship (SEM Analytics)

## 📌 Overview  
Worked on paid search (SEM) campaigns across Google Ads and Bing Ads, focusing on performance analysis, budget optimization, and client reporting.

---

## 🚀 Key Highlights  

- 📊 Analyzed campaign performance using KPIs such as CTR, CPC, conversions, and ROAS  
- 💰 Managed budget pacing by adjusting daily spend and reallocating budget to high-performing campaigns  
- 📑 Created client-facing reports summarizing key wins, challenges, and performance insights  
- 🛍️ Evaluated promotional campaigns (Cyber Sale) using YoY and PoP analysis to guide strategy  
- 🤝 Translated data into clear insights to support client communication and decision-making  
- 📢 Built and optimized campaigns using Google Ads Editor and earned Google Ads Search Certification  
- 🛒 Worked with Google Merchant Center to manage product data and improve ad performance  

---

## 🛠️ Tools  
Google Ads • Bing Ads • Excel • PowerPoint • Google Merchant Center • FileZilla  

---

## 📊 Impact  
- Strengthened ability to connect data insights to business decisions  
- Improved campaign optimization and performance analysis skills  
- Gained experience presenting data to non-technical stakeholders
